PREGUNTAS CLAVE DEL PROYECTO

Extracto de las preguntas más importantes formuladas en la guía consolidada para la defensa del stand.

01. ¿Qué problema real resuelve nuestro robot y a quién beneficia?

Resuelve la vulnerabilidad de las plantas ante climas desfavorables e inestables en espacios reducidos o de cultivo en interiores. Permite automatizar el control térmico y de humedad sin intervención continua del usuario, beneficiando a pequeñas familias, escuelas e iniciativas de agricultura urbana sostenible.

02. ¿Por qué es un sistema de control de lazo cerrado?

Porque no opera de forma fija o con horarios rígidos; utiliza sensores (TMP36 y humedad del suelo) para medir continuamente las variables reales del entorno y retroalimentar al microcontrolador Arduino UNO, el cual toma decisiones en tiempo real sobre los actuadores.

03. ¿Cómo se protegen los componentes electrónicos del agua?

Mediante un diseño con aislamiento por zonas: la parte electrónica (Arduino, protoboard, pantalla LCD y buzzer) se ubica en un compartimento superior seco, mientras que las sondas de medición y el depósito de agua permanecen aislados en la parte inferior.

04. ¿Por qué se utilizan relés u optoacopladores para las cargas pesadas?

Los pines digitales del ATmega328P entregan un máximo de 40 mA por puerto. Componentes como bombas o ventiladores demandan más corriente y pueden dañar el chip. El relé aísla la lógica de control (5V) de la etapa de potencia externa.

Código C++ del Firmware Arduino IDE 

#include <Adafruit_LiquidCrystal.h>
#include <Servo.h>

int TEMPERATURA = 0;
int HUMEDAD = 0;

Adafruit_LiquidCrystal lcd_1(0);
Servo servo_7;

void setup() {
  lcd_1.begin(16, 2);
  pinMode(A0, INPUT);
  pinMode(A1, INPUT);
  Serial.begin(9600);
  
  servo_7.attach(7, 500, 2500);
  pinMode(8, OUTPUT);
  pinMode(13, OUTPUT); // Buzzer de alarma

  lcd_1.setBacklight(1);
}

void loop() {
  // Conversión de lecturas analógicas
  TEMPERATURA = (-40 + 0.488155 * (analogRead(A0) - 20));
  HUMEDAD = map(analogRead(A1), 0, 1023, 0, 117);

  // Mapeo en LCD
  lcd_1.setCursor(0, 0);
  lcd_1.print("T=      ");
  lcd_1.setCursor(2, 0);
  lcd_1.print(TEMPERATURA);

  lcd_1.setCursor(0, 1);
  lcd_1.print("H=      ");
  lcd_1.setCursor(2, 1);
  lcd_1.print(HUMEDAD);

  // Posiciones por defecto
  servo_7.write(0);
  digitalWrite(8, LOW);

  // Control térmico por ventana
  if (TEMPERATURA > 30 && TEMPERATURA <= 40) {
    servo_7.write(90);
  } 

  // Alarma crítica por sobretemperatura
  if (TEMPERATURA > 40 && TEMPERATURA <= 50) {
    servo_7.write(90);
    digitalWrite(8, HIGH);
    tone(13, 1661, 1000);
  }

  // Alarma por fuera de rango de humedad
  if (HUMEDAD < 30 || HUMEDAD > 70) {
    tone(13, 1200, 500);
  }

  delay(500);
}
